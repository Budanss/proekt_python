# API Tests — User Creation

## 📌 Описание проекта

Данный репозиторий содержит автотесты для проверки API создания пользователя.

Основная цель проекта - протестировать бизнес-логику валидации поля firstName при создании пользователя через HTTP API.

Тесты реализованы на Python с использованием библиотеки requests и фреймворка pytest.

---

## 🧠 Проверяемый функционал

В рамках проекта покрыты следующие сценарии:

### ✅ Позитивные проверки:
- создание пользователя с корректным именем
- минимальная допустимая длина имени (2 символа)
- максимальная допустимая длина имени (15 символов)
- использование различных алфавитов (латиница, кириллица)

### ❌ Негативные проверки:
- слишком короткое имя (1 символ)
- слишком длинное имя (более 15 символов)
- использование недопустимых символов (спецсимволы, цифры)
- отсутствие обязательного поля firstName
